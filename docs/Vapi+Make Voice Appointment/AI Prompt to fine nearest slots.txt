# Available Slot Selection

Preferred Time: {{14.preferedTime}}

Busy Slots: {{`22`}}
 
The CheckSlotAvailability tool returns the doctor's busy appointment slots for the requested date.

The clinic's working hours are:

- Opening Time: 9:00 AM
- Closing Time: 5:00 PM

Appointments can only be scheduled between 9:00 AM and 5:00 PM.

Your task is to determine the closest available appointment slots based on the patient's preferred appointment time.

Rules:

- Treat the returned slots as busy and unavailable.
- Do not return any busy slot.
- Only suggest appointment times between **9:00 AM and 5:00 PM**.
- Do not suggest appointment times before 9:00 AM or after 5:00 PM.
- Find the nearest available slots before or after the patient's preferred appointment time.
- Prioritize slots closest to the preferred time.
- Return a maximum of 3 available slots.
- Sort the available slots by proximity to the preferred time.
- If the preferred time is available, return it first.
- Follow the clinic's appointment duration when determining available slots.
- If no suitable slots are available during clinic hours, politely ask the patient to choose another date.

Example:

Preferred Time:
3:00 PM

Busy Slots:
[
  "2:30 PM",
  "3:00 PM",
  "4:00 PM"
]

Assistant Response:

"1) 3:30 PM 2) 4:30 PM 3) 2:00 PM"

Never display busy slots as available.
Never create an appointment during this step.
Only suggest the nearest available appointment slots within the clinic's working hours (9:00 AM to 5:00 PM).

## Available Slot Selection

Preferred Time: `{{14.preferedTime}}`
Busy Slots: `{{22}}`

Clinic Hours: **9:00 AM–5:00 PM**

Return up to **3** available appointment times.

Rules:

* Busy Slots are unavailable.
* Suggest only times between **9:00 AM and 5:00 PM**.
* Prefer the patient's requested time if available.
* Otherwise suggest the nearest available times before or after it.
* Sort by closest to the preferred time.
* Never return a busy slot.
* Never create an appointment.
* If no slot is available, ask the patient to choose another date.

Example:

Preferred: **3:00 PM**

Busy:
`["2:30 PM","3:00 PM","4:00 PM"]`

Response:
`1. 3:30 PM`
`2. 4:30 PM`
`3. 2:00 PM`
